# 3단계 작업 분해 (테스트 · 강의자료)

> 상태: 초안 · v0.9 — [planning/roadmap.md](../planning/roadmap.md)의 3단계를 개발 작업으로 나눈 것. 형식은 [phase2-plan.md](./phase2-plan.md)와 같다.

3단계 완료 기준(로드맵): **레슨 → 단어 → 테스트 흐름을 끝까지 진행 가능**

## 범위 (기능명세의 "3단계" 목록)
- 테스트: TST-01~04, 07~08, 10~17, 19, 20~23, 30~32, 34 (유형: 객관식, OX, 단답, 서술형)
- 통합 오답 노트: WRN-01, 03, 10~11, 20~22
- 강의자료: CRS-01~03, 06, 10~16, 20~23
- 미션: MIS-16 (시험·레슨·함께 읽기에서 미션 만들기)
- 독서: READ-15, 22, 32, 40~45, 51
- 단어: VOC-12, 24~25, 43
- 노트: NOTE-06, 11, 24~25, 38, 43, 62~63, 70~71
- 독후감: REV-08, 13, 20
- 공통: CMN-31, 50
- 계정: ACC-21, 24, 31, 40~41
- 워크스페이스: WS-61 중 문제·문제집·코스 복사

## 작업 분해

### 3-A 문제 은행 (테스트의 기반, 먼저)
| # | 작업 | 기능 ID |
| --- | --- | --- |
| 3-A1 | 문제 만들기(객관식·OX·단답·서술형), 지문 이미지·오디오(파일 기능 재사용), 과목·태그·난이도·배점. 정답·해설은 본문과 다른 문서에 두어 규칙으로 가린다. 진행: 유형 5종·정답 분리·내 문제/공유된 문제·태그 필터 완료, 지문 이미지·오디오는 남음 | TST-01·02 |
| 3-A2 | 내 문제 / 공유된 문제 탭, 필터, 공유, 정답 공개 설정, 다른 공간으로 복사. 진행: 탭·공유·정답 공개는 3-A1에서, 과목 필터·지문 이미지·오디오·복사(TST-40) 완료. 수식은 4단계 | TST-04·07·08·40, WS-61 |
| 3-A3 | 단어장에서 문제 자동 생성. 진행: 뜻→단어·단어→뜻 객관식, 뜻→단어·단어→뜻 단답 4종, 카드 수·배점·공유 설정 완료 | TST-03 |

### 3-B 시험 출제 · 응시 · 채점
| # | 작업 | 기능 ID |
| --- | --- | --- |
| 3-B1 | ✅ 시험 만들기: 문제 구성(직접·조건 무작위), 시간 제한, 응시 기간·횟수, 섞기, 결과 공개, 대상. 시험을 열 때 문제를 시험지 사본으로 굳히고 정답 사본은 서버만 읽는다(`openTest`) | TST-10~16 |
| 3-B2 | ✅ 응시: 안내, 응시 화면, 자동 저장(서버 시각 기준으로 시간 계산), 제출·시간 초과 자동 제출, 연습 모드 | TST-17·20~23 |
| 3-B3 | ✅ 채점: 객관식·OX·단답은 서버 함수가 제출 즉시 채점, 서술형 채점 대기·부분 점수·코멘트, 내 결과. "내가 이끄는 것"에 채점 대기 추가 | TST-30~32, CMN-06 |
| 3-B4 | ✅ 시험을 미션으로 배정(응시 또는 목표 점수 달성 시 완료). 시험을 열 때 서버가 연결 미션을 만들고, 제출·채점 함수가 완료를 기록한다 | TST-19, MIS-16 |
| 3-B5 | ✅ 단어장 테스트 자동 생성 → 시험 기능으로 응시. 단어장 화면 "테스트"에서 객관식·단답·OX를 섞어 문제를 만들고 시험 초안까지 만든 뒤, 시간·대상을 정해 연다. 짝맞추기는 문제 유형(TST)이 생기면 추가 | VOC-25 |

## 순서 (초안)
3-A → 3-B → 3-C (완료 기준) → 3-D → 3-E → 3-F → 3-G → 3-H, 각 묶음 끝에 규칙 테스트.

## 리뷰 질문
- 푸시 알림(3-H2)에는 Firebase 콘솔에서 만드는 웹 푸시 키(VAPID)가 필요하다. 그 단계에서 요청한다.
- 회원 탈퇴(3-H3) 때 워크스페이스 소유자인 경우: 소유권을 넘겨야 탈퇴 가능하게 할지.
