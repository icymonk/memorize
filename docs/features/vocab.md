# 외국어 학습 (Quizlet형)

> 상태: 확정 · v1.1 · ID 접두어 `VOC`

## 1. 목적
단어장을 함께 만들고, 다양한 학습 모드와 간격 반복 복습으로 효율적으로 외운다.

## 2. 사용자 스토리
- 단어 목록을 엑셀/텍스트에서 붙여넣어 빠르게 단어장을 만들고, 내가 만든 단어장으로 나도 공부하고 싶다.
- 스터디원끼리 단어장을 나눠 만들고(Day 1~10은 나, 11~20은 친구) 서로의 단어장으로 공부하고 싶다.
- 지하철에서 카드를 넘기며 외우고, 틀린 단어만 다시 보고 싶다.
- 오늘 복습할 단어를 여러 단어장에 걸쳐 한 번에 복습하고 싶다.
- 매칭 게임 기록을 친구와 겨루고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 단어장 | 카드 묶음. 언어쌍(예: 영어 → 한국어)이 있다 |
| 카드 | 앞면(단어)과 뒷면(뜻) + 예문·발음 등 |
| 학습 상태 | 카드마다 나의 상태: 새 카드 / 학습 중 / 복습 / 외움 |
| 간격 반복 복습 | 잊어버릴 때쯤 다시 보여주는 복습 방식. 잘 아는 카드는 간격이 길어진다 |

## 7. 예외 상황
- 공부 중인 단어장의 카드가 수정됨 → 내 학습 상태는 유지, 뜻이 크게 바뀐 경우 "새 카드"로 되돌릴지 묻기.
- 카드가 삭제됨 → 그 카드의 내 기록도 사라지고 진도율 다시 계산.
- 단어장이 삭제됨 → 복사해 간 단어장은 남는다. 학습 기록은 사라지지만 활동 피드·일지 요약 기록은 남는다.
- 붙여넣기에서 구분자를 못 찾은 줄 → 미리보기에서 빨간색 표시, 저장 전 수정.
- 카드가 1~3장뿐 → 매칭·객관식 모드 비활성화하고 이유 표시.
