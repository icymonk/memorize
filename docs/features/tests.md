# 테스트

> 상태: 확정 · v1.1 · ID 접두어 `TST`

## 1. 목적
과목에 상관없는 **문제 은행**으로 시험을 만들고, 응시·채점·분석까지 지원한다. 외국어·수학 기능이 이 기능을 함께 쓴다.
**누구나 문제를 만들고 시험을 열 수 있고**, 다른 사람이 연 시험에는 응시자로 참여한다.

## 2. 사용자 스토리
- 문제를 한 번 만들어 두고 여러 시험에 다시 쓰고 싶다.
- 시간 제한과 응시 기간을 정해 그룹별로 시험을 열고 싶다.
- 스터디원끼리 돌아가며 주간 모의 테스트를 출제하고, 출제하지 않은 주에는 응시하고 싶다.
- 시험 후 틀린 문제와 해설을 보고 오답 노트에 쌓고 싶다.
- 내가 연 시험의 문제별 정답률을 보고 다음 출제에 반영하고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 문제 은행 | 출제자별 "내 문제" + 다른 사람이 공유한 문제 |
| 출제자 | 문제를 만든 사람 + 공동 출제자. 정답·해설은 **기본적으로 출제자만** 보고, 출제자가 공개할 수 있다 (TST-07) |
| 진행자 | 시험을 연 사람 + 공동 진행자 |
| 응시자 | 시험 대상으로 지정된 사람 |
| 연습 응시 | 진행자나 출제자가 직접 응시한 경우. 평균·순위에서 빠진다 |

- 다른 사람의 문제를 내 시험에 넣을 수 있다. 채점은 자동으로 되므로 진행자가 정답을 몰라도 된다.
- 서술형처럼 직접 채점해야 하는 문제는 진행자에게 채점 기준이 함께 보인다.

## 4. 기능 명세

### 문제 은행
| ID | 기능 | 설명 |
| --- | --- | --- |
| TST-01 | 문제 만들기 | 지문(이미지·오디오·수식 가능), 정답, 해설, 과목, 태그, 난이도, 기본 배점 |
| TST-02 | 문제 유형 | 아래 표 |
| TST-03 | 단어장에서 문제 만들기 | 단어장을 고르면 "뜻 → 단어" 객관식, "단어 → 뜻" 단답 등 자동 생성 |
| TST-04 | 문제 찾기 | 탭: 내 문제 / 공유된 문제. 과목, 태그, 난이도, 출제자로 필터 |
| TST-05 | 공동 출제자 | 다른 멤버를 공동 출제자로 추가 |
| TST-06 | 문제 통계 | 출제자는 내 문제가 쓰인 시험들의 정답률을 볼 수 있다 |
| TST-07 | 정답 공개 설정 | 문제(또는 문제 묶음)마다 정답·해설을 **출제자만(기본)** / 워크스페이스 멤버에게 공개 중 선택. 정답이 공개된 문제를 정식 시험에 넣으면 "정답이 공개된 문제" 경고 |
| TST-08 | 문제 공유 | 새 문제는 **기본 "내 문제"(비공유)**. 원하는 문제·문제 묶음을 워크스페이스에 공유. 공유된 문제는 다른 사람이 자기 시험에 넣거나 **복사해 가져가기**(내 문제가 되어 수정 가능). 원본이 수정되면 복사해 간 사람에게 "원본이 수정됨" 알림과 변경 내용 보기·반영하기 |
| TST-09 | 파일 가져오기/내보내기 | 문제를 엑셀 등 파일로 내보내고 가져오기 |
| TST-40 | 다른 워크스페이스로 복사 | 내 문제·문제 묶음을 내가 속한 다른 워크스페이스로 복사 → [workspace.md](./workspace.md) WS-60~64 |

| ID | 기능 | 설명 |
| --- | --- | --- |
| TST-20 | 시험 안내 | 문제 수, 시간, 남은 응시 횟수, 마감 |

## 7. 예외 상황
- 응시 중 인터넷 끊김 → 다시 연결되면 이어서. 끊긴 동안 쓴 답은 기기에 보관 후 전송.
- 응시 중 마감 시각 도달 → 그때까지의 답으로 자동 제출.
- 시험이 시작된 뒤 문제 수정 → 이미 응시한 사람의 점수는 그대로. 진행자가 "다시 채점" 선택 가능.
- 시험에 쓰인 문제를 출제자가 삭제 → 시험에서는 사본으로 유지.
- 진행자가 자기 시험에 응시 → 연습 응시로 표시.
