# 공통 기능 (홈 · 피드 · 댓글/피드백 · 알림 · 포인트 · 검색)

> 상태: 확정 · v1.1 · ID 접두어 `CMN`

모든 학습 기능이 함께 쓰는 기능. 각 기능 문서에서는 여기 정의를 가져다 쓴다.

## 1. 목적
- 어떤 기능을 쓰든 홈에서 오늘 할 일을 보고, 같은 방식으로 댓글·피드백·알림을 주고받게 한다.
- 배우기·만들기·이끌기가 모두 보상받아 역할이 자연스럽게 돌게 한다.

## 2. 사용자 스토리
- 앱을 열면 오늘 복습할 단어, 진행 중 미션, 오늘 일지 작성 여부를 한눈에 보고 싶다.
- 내가 연 미션에 제출이 들어오면 바로 알고 싶다.
- 친구 독후감에 피드백을 남기고, 내 글에는 원하는 사람에게 피드백을 요청하고 싶다.
- 워크스페이스에서 누가 무엇을 했는지 피드로 보며 자극을 받고 싶다.

## 3. 기능 명세

### 홈
| ID | 기능 | 설명 |
| --- | --- | --- |
| CMN-01 | 오늘의 할 일 | 복습할 카드 수, 진행 중 미션(마감 순), 응시할 테스트, 읽는 중인 책 |
| CMN-02 | 오늘의 학습일지 | 작성 여부 + "작성하기" 바로가기 |
| CMN-03 | 나의 기록 | 연속 학습일, 이번 주 학습 시간·포인트, 학습 잔디 |
| CMN-04 | 활동 피드 미리보기 | 최근 활동 5개 + 더보기 |
| CMN-05 | 랭킹 | 주간 포인트 순위 (**기본 켜짐**, 워크스페이스 설정에서 끌 수 있음) |
| CMN-06 | 내가 이끄는 것 | 내가 연 미션·테스트·함께 읽기의 현황, 검토/채점 대기, 피드백 요청받은 글. **해당 항목이 있을 때만** 보인다 |

- 홈은 모든 멤버에게 같은 구성이다. 역할에 따라 다른 화면이 나오지 않는다.

### 활동 피드
| ID | 기능 | 설명 |
| --- | --- | --- |
| CMN-10 | 피드 | 워크스페이스 활동을 시간순으로. 큰 활동(단어장 완료, 새 단어장, 책 완독, 독후감 발행, 미션 완료, 테스트 응시)과 작은 활동(단어 n개 복습, 독서 기록, 일지 작성 등) 모두 올린다 |
| CMN-11 | 필터 | 기능별, 멤버별, "큰 활동만" |
| CMN-12 | 반응 | 피드 항목에 이모지 반응 |
| CMN-13 | 활동 크기 구분 | 큰 활동은 카드(이미지·요약 포함)로 눈에 띄게, 작은 활동은 한 줄로 작게. 같은 사람의 같은 날 작은 활동은 하나로 묶어 "민수 · 단어 120개 복습, 독서 30쪽" 식으로 표시 |

- 비공개 노트, 숨긴 진도는 피드에 나오지 않는다.

| --- | --- | --- |
| CMN-20 | 댓글 | 노트·독후감·일지, 미션 제출물, 단어장, 테스트 결과 등에 공통으로 사용. 수정·삭제 가능 |

### 포인트 · 뱃지 · 랭킹
| ID | 기능 | 설명 |
| --- | --- | --- |
| CMN-40 | 포인트 | 아래 행동마다 적립. 워크스페이스에서 조정 가능 |
| CMN-41 | 연속 학습일 | 하루에 한 번 이상 학습하면 이어진다 (내 시간대 기준) |
| CMN-42 | 뱃지 | 배우기·만들기·이끌기 각각의 뱃지 |
| CMN-43 | 랭킹 | 주간/월간 포인트 순위 |

기본 포인트:

| 행동 | 포인트 |
| --- | --- |
| 카드 10장 복습 | 1 |
| 학습 한 회 완료 | 5 |
| 학습일지 작성 | 5 |
| 독서 기록 | 3 |
| 독후감 발행 | 20 |
| 미션 완료 | 미션마다 지정 |
| 테스트 응시 | 10 (+ 점수 보너스) |
| 공유 콘텐츠 만들기 (단어장·문제·강의자료) | 10 |
| 미션·테스트 진행, 피드백 남기기 | 5 |

뱃지 예시: 7일 연속, 단어 1000개 암기, 책 10권 완독, 일지 30일, 첫 단어장 제작, 미션 5회 진행, 피드백 20회.

#### 악용·오용 방지
| ID | 규칙 | 설명 |
| --- | --- | --- |
| CMN-70 | 하루 상한 | 행동 종류별 하루 최대 포인트 (예: 복습 포인트 하루 최대 20) |
| CMN-71 | 반복 감소 | 같은 단어장·같은 문제를 짧은 시간에 반복하면 포인트가 점점 줄어듦 |
| CMN-72 | 만들기 포인트는 사용될 때 | 단어장·문제·강의자료를 만들면 바로 주지 않고, **다른 멤버가 실제로 학습·응시했을 때** 적립. 카드 몇 장짜리 빈 단어장으로는 적립 안 됨(최소 분량) |
| CMN-73 | 이끌기 포인트 조건 | 미션·테스트 진행 포인트는 **다른 참여자가 1명 이상** 있을 때만. 개인 목표는 진행 포인트 없음 |
| CMN-74 | 피드백 포인트 조건 | 스탬프만 누른 피드백은 적은 포인트, 코멘트가 있으면 정상 포인트. 같은 사람에게 하루 몇 회까지만 |
| CMN-75 | 서로 주고받기 방지 | 두 사람이 서로에게만 반복해서 피드백·검토하는 경우 포인트 감소 |
| CMN-76 | 삭제 시 회수 | 콘텐츠를 지우면 그것으로 받은 포인트 회수 |
| CMN-77 | 운영자 조정 | 소유자·매니저가 포인트 내역을 보고 조정·회수 가능 (멤버에게 알림, 기록 남음) |
| CMN-78 | 이상 표시 | 짧은 시간에 포인트가 급격히 늘면 소유자·매니저에게 알림 |

## 5. 예외 상황
- 피드백 요청을 받은 사람이 워크스페이스를 나감 → 요청 자동 취소.
- 댓글이 달린 글이 비공개로 바뀜 → 댓글은 남지만 글쓴이만 볼 수 있다.
- 시간대가 다른 멤버끼리의 연속 학습일 → 각자 자기 시간대 기준.
- 업로드 용량을 다 씀 → 업로드 전에 안내, 내 용량 보기로 이동. 이미 올린 파일은 그대로 보인다.
- 업로드한 사람이 워크스페이스를 나감 → 공유 콘텐츠에 들어간 파일은 남고, 용량은 계속 그 사람 몫으로 계산 (탈퇴 시 해제).
