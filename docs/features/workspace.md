# 워크스페이스 · 멤버 · 초대 · 그룹

> 상태: 확정 · v1.2 · ID 접두어 `WS`

## 1. 목적
함께 공부하는 모임의 단위이자 **공유의 경계**. 같은 워크스페이스 멤버끼리만 콘텐츠와 활동을 공유한다.

## 2. 사용자 스토리
- 워크스페이스를 만들고, 쓸 기능만 켜서 화면을 단순하게 유지하고 싶다.
- 초대 링크/코드를 공유해 친구·가족·학생들을 쉽게 들어오게 하고 싶다.
- 멤버를 그룹(반, 조)으로 나눠 미션과 테스트를 그룹별로 열고 싶다.
- 학원·가족·스터디처럼 여러 워크스페이스를 빠르게 오가고 싶다. 워크스페이스마다 내가 하는 일(배우기/만들기/이끌기)은 다를 수 있다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 워크스페이스 | 함께 공부하는 모임. 한 사람이 여러 곳에 속할 수 있다 |
| 그룹 | 워크스페이스 안의 작은 묶음 (반, 조). 한 사람이 여러 그룹에 속할 수 있다 |
| 운영 권한 | 소유자 / 매니저 / 멤버. 워크스페이스 관리에만 쓰이며 학습 기능과 무관 → [users-and-roles.md](../planning/users-and-roles.md) |

### 내 공간 (워크스페이스 밖)
워크스페이스에 속하지 않는, **나만의 학습 공간**. 혼자 공부할 때나 워크스페이스에 올리기 전 준비용으로 쓴다.

| ID | 기능 | 설명 |
| --- | --- | --- |
| WS-50 | 내 공간 | 모든 사용자에게 처음부터 있다. 사이드바 맨 위, 워크스페이스 목록 위에 표시. **나만 볼 수 있다** (아이 계정은 보호자도 볼 수 있음) |
| WS-51 | 들어가는 것 | **개인 단어장**([vocab.md](./vocab.md)), **개인 노트·모음**([notes.md](./notes.md)), **개인 독서**(내 책장·독서 기록·구절·통계, [reading.md](./reading.md))와 **독후감**([book-reviews.md](./book-reviews.md)). 쓰는 방법은 워크스페이스와 같다. 미션·테스트·함께 읽기·피드백 같은 함께하는 기능은 워크스페이스 전용 |
| WS-52 | 워크스페이스로 복사 | 내 공간의 단어장·노트를 원하는 워크스페이스로 복사. 반대로 워크스페이스에서 볼 수 있는 단어장·노트를 내 공간으로 복사 |
| WS-53 | 전체 오늘의 복습 | 내 공간 홈에서 **내 공간 + 모든 워크스페이스**의 오늘 복습할 카드를 한 번에. 각 워크스페이스 안의 오늘의 복습은 그 워크스페이스 것만 |
| WS-54 | 내 공간 홈 | 전체 오늘의 복습, 모든 워크스페이스의 오늘 할 일 요약, 내 일지 모아 보기([notes.md](./notes.md) NOTE-39), 최근 노트, 읽는 중인 책 |

- 내 공간 학습도 개인 연속 학습일·통합 학습 현황([account.md](./account.md) ACC-30)에 포함된다. 워크스페이스 포인트·랭킹·활동 피드에는 들어가지 않는다.
- 워크스페이스를 나가거나 내보내져도 내 공간은 그대로다. 탈퇴하면 삭제된다.
- 업로드 용량은 계정당 한도([common.md](./common.md) CMN-61)에 함께 계산된다.

## 7. 예외 상황
- 만료되었거나 꺼진 초대 링크 → "사용할 수 없는 초대입니다" + 워크스페이스 이름만 표시.
- 이미 멤버인 사람이 초대 링크로 들어옴 → 해당 워크스페이스로 바로 이동.
- 내보내진 사람이 다시 같은 링크로 들어옴 → 승인 방식처럼 대기 상태로 처리.
- 소유자가 탈퇴하려 함 → 소유권을 넘기거나 워크스페이스를 삭제해야 탈퇴 가능.
- 마지막 멤버(소유자 혼자)가 나가려 함 → 워크스페이스 삭제로 안내.
- 인원이 가득 찬 상태에서 초대 링크로 들어옴 → "인원이 가득 찼습니다" 안내, 소유자·매니저에게 알림.
- 진행 중인 미션·테스트·함께 읽기의 대상 그룹을 삭제하려 함 → "이 그룹을 대상으로 하는 활동이 있습니다" 경고. 삭제해도 그 활동의 참여자는 그대로 유지.
- 워크스페이스에 하나도 속하지 않은 사용자 → 첫 화면에서 내 공간으로 바로 들어간다. 워크스페이스 만들기·참여는 언제든 가능.
- 복사할 곳에서 "공유 콘텐츠 작성 가능자"가 아님 → 그 워크스페이스는 복사 대상 목록에서 비활성화하고 이유 표시.
- 복사하려는 콘텐츠에 내가 볼 수 없는 연결 항목(다른 사람의 비공개 노트 링크 등)이 있음 → 그 연결은 빼고 복사.
