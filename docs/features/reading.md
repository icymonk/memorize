# 독서

> 상태: 확정 · v1.1 · ID 접두어 `READ`

## 1. 목적
읽는 책을 각자 등록하고, 독서 진행을 기록하며, 원할 때는 그룹이 함께 읽는 경험을 만든다. 다 읽은 책은 독후감([book-reviews.md](./book-reviews.md))으로 이어진다.

## 2. 사용자 스토리
- 내가 읽는 책을 내 책장에 올리고, 읽은 쪽과 시간을 간단히 기록하고 싶다.
- 종이책뿐 아니라 전자책·오디오북도 기록하고 싶다.
- 마음에 드는 구절을 저장하고 멤버들과 공유하고 싶다.
- 다른 멤버들이 요즘 무슨 책을 읽는지 보고 싶다.
- "이번 달 함께 읽을 책"을 누구든 개설하고, 주차별 읽을 범위를 정해 함께 읽고 싶다.
- 1년 동안 몇 권을 읽었는지 한눈에 보고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 내 책장 | 내가 등록한 책과 상태. **책은 각자 자기 책장에 등록한다** |
| 워크스페이스 책장 | 멤버들의 책장을 모아 보여주는 곳. 같은 책은 하나로 묶여 "이 책을 읽는 멤버"가 함께 보인다 |
| 독서 기록 | 언제 어디부터 어디까지, 몇 분 읽었는지 |
| 구절 | 책에서 저장한 문장 |
| 함께 읽기 | 기간을 정해 여러 명이 같은 책을 읽는 모임 (선택) |

> **내 공간에서도** 내 책장·독서 기록·구절·통계·연간 목표를 쓸 수 있다 ([workspace.md](./workspace.md) WS-51). 워크스페이스 책장·책 추천·함께 읽기는 워크스페이스에서만.

## 4. 기능 명세

### 책 등록
| ID | 기능 | 설명 |
| --- | --- | --- |
| READ-01 | 책 검색해서 담기 | 제목·저자·ISBN으로 검색 → 표지·저자·쪽수 자동 입력 → 내 책장에 추가 |
| READ-02 | 직접 등록 | 검색이 안 되는 책: 제목, 저자, 표지 사진, 분량 |
| READ-03 | 같은 책 묶기 | 다른 멤버도 같은 책을 담았으면 워크스페이스 책장에서 하나로 묶어 보여준다 |
| READ-04 | 바코드 스캔 | 휴대폰 카메라로 책 뒷면 바코드 (이후 단계) |
| READ-05 | 책 형식 | 종이책(쪽) / 전자책(% 또는 쪽) / 오디오북(시간). 형식에 따라 진행률과 기록 단위가 바뀐다 |

### 책장
| ID | 기능 | 설명 |
| --- | --- | --- |
| READ-10 | 내 책장 상태 | 읽고 싶음 / 읽는 중 / 다 읽음 / 그만 읽음 |
| READ-11 | 책별 내 정보 | 현재 위치(쪽·%·시간), 시작일, 완독일, 별점 |
| READ-12 | 보기 | 표지 격자 / 리스트, 상태별 탭 |
| READ-13 | 워크스페이스 책장 | 멤버들이 읽는·읽은 책 모아 보기, 책마다 읽는 멤버 |
| READ-14 | 다른 멤버 책 담기 | 워크스페이스 책장에서 "나도 읽기"로 내 책장에 추가 |
| READ-15 | 책 추천 | 워크스페이스 책장 위쪽에 묶음으로 표시: **요즘 많이 읽는 책**, **멤버 별점이 높은 책**, **독후감이 많은 책**, **내가 읽은 책과 비슷한 책**(같은 저자·장르·태그), 함께 읽기 후보 추천 |

### 독서 기록
| ID | 기능 | 설명 |
| --- | --- | --- |
| READ-20 | 기록하기 | 날짜, 범위(종이책: 쪽 / 전자책: % / 오디오북: 들은 시간), 읽은 시간, 한 줄 메모 |
| READ-21 | 빠른 기록 | 책 카드에서 "오늘 ○쪽까지" 한 번에 |

## 7. 예외 상황
- 같은 책인데 판본이 달라 쪽수가 다름 → 각자 자기 책장의 분량 기준으로 진행률 계산. 함께 읽기 일정은 챕터 기준 권장.
- 기록한 위치가 이전 기록보다 앞 → "다시 읽기"로 처리할지 묻기.
- 함께 읽기 기간이 끝남 → 결과 요약(완독한 멤버 수 등)을 남기고 종료 상태.
- 내 책장에서 책을 삭제 → 기록·구절도 지울지 묻기. 독후감은 남는다.
- 진도 숨기기를 켠 멤버 → 워크스페이스 책장·함께 읽기 현황에서 **진행률·기록은 숨기고, 읽는 책 제목은 보여준다.**
