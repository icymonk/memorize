# 미션

> 상태: 확정 · v1.0 · ID 접두어 `MIS`

## 1. 목적
**누구나 미션을 열 수 있다.** 미션을 연 사람(진행자)이 대상을 정하고, 자동 또는 직접 완료를 확인하는 **공통 과제 기능**. 모든 학습 기능과 연결된다.

## 2. 사용자 스토리
- "이번 주 Day 5 단어장 100% 외우기" 미션을 워크스페이스 전체에 열고, 나도 함께 참여하고 싶다. 달성 여부는 자동으로 체크되면 좋겠다.
- 가족 누구든 "매일 학습일지 쓰기" 습관 미션을 열 수 있으면 좋겠다 (아이가 엄마에게 열어줄 수도 있다).
- 내가 참여 중인 미션과 마감일, 내가 연 미션의 현황을 한눈에 보고 싶다.
- 나만의 목표(하루 30분 독서)를 미션으로 만들고 싶다.
- 미션을 열 때 검토를 함께 할 사람(리뷰어)을 지정하고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 진행자 | 미션을 연 사람 + 공동 진행자 |
| 리뷰어 | 진행자가 지정한, 제출물을 함께 검토하는 사람 |
| 참여자 | 대상으로 지정되었거나 "참여하기"로 합류한 사람 |
| 열린 미션 | 대상이 아니어도 누구나 참여할 수 있는 미션 |
| 개인 목표 | 나 자신만 대상인 미션 |

- 진행자가 대상에 자신을 넣으면 **진행자이자 참여자**가 된다.

## 4. 기능 명세

### 미션 종류
| ID | 종류 | 완료 판정 | 예시 |
| --- | --- | --- | --- |
| MIS-01 | 체크형 | 참여자가 스스로 "완료" 체크 | 매일 줄넘기, 영어 일기 쓰기 |
| MIS-02 | 제출형 | 참여자가 제출 → 진행자·리뷰어가 승인/반려 | 글, 사진, 파일, 독후감, 노트 제출 |
| MIS-03 | 자동 확인형 | 학습 기록을 보고 자동으로 완료 | 아래 표 |

자동 확인 조건:

| 조건 | 설정값 |
| --- | --- |
| 단어장 외우기 | 단어장, 목표 % |
| 연속 복습 | 일 수 |
| 테스트 점수 | 테스트, 목표 점수 |
| 책 완독 | 책 |
| 독서 쪽수 | (책), 쪽 수 |
| 학습일지 작성 | 기간 내 횟수 |
| 학습 시간 | 분 |
| 레슨 완료 | 코스/레슨 |

| MIS-36 | 서로 검토 조건 | "검토를 n개 해야 내 미션도 완료" 선택 가능. 검토자는 **기본 이름 공개** (익명으로 바꿀 수 있음) |

## 7. 예외 상황
- 자동 확인형의 대상 단어장·테스트가 삭제됨 → 진행자에게 알림, 미션은 체크형으로 전환할지 선택.
- 대상 그룹에 나중에 들어온 멤버 → 진행 중 미션에 자동 참여 (지난 회차는 제외).
- 반려 후 다시 제출 → 같은 회차에 다시 제출 가능 (마감 전까지).
- 진행자가 워크스페이스를 나감 → 공동 진행자가 있으면 이어받음, 없으면 매니저에게 넘기거나 종료.
- 반복 미션 중간에 참여 → 참여한 날부터의 회차만 집계.
- 서로 검토인데 참여자가 너무 적음(2명 이하) → 서로 검토 대신 진행자 검토로 안내.
- 배정된 검토자가 기한 내 검토하지 않음 → 다른 참여자에게 다시 배정.

## 8. 출시 단계
- 1단계: MIS-14 중 **간단한 개인 목표(체크형만, 1회/매일 반복)**
- 2단계: MIS-01~02, MIS-10~12, MIS-14(전체), MIS-17, MIS-20~24, MIS-30~32, MIS-34, MIS-40
- 3단계: MIS-16 (시험·레슨 연결)
- 4단계: MIS-03, MIS-13, MIS-15, MIS-33, MIS-35~36
