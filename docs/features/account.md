# 계정 · 프로필 · 개인 설정

> 상태: 확정 · v1.1 · ID 접두어 `ACC`

## 1. 목적
가입과 로그인을 간단하게 하고, 여러 워크스페이스에 걸친 나의 정보와 설정을 관리한다.

## 2. 사용자 스토리
- 비밀번호 없이 구글 계정이나 이메일 링크로 빠르게 가입하고 싶다.
- 워크스페이스마다 다른 닉네임을 쓰고 싶을 때가 있다 (가족방에서는 "엄마", 스터디에서는 실명).
- 알림을 너무 많이 받지 않도록 종류별로 끄고 싶다.
- 모든 워크스페이스에서의 내 학습을 한 번에 보고 싶다.

| ACC-06 | 보호자가 만드는 아이 계정 | 보호자가 자기 계정에서 아이 계정을 만들고 관리. 아이는 이메일 없이 보호자가 발급한 로그인 코드(또는 QR)로 로그인 |

| ACC-09 | 보호자 여러 명 | 아이 한 명에 보호자 여러 명(엄마·아빠 등) 연결. 보호자가 다른 보호자를 초대하고, 모든 보호자는 같은 권한 |

## 5. 예외 상황
- 이메일 링크를 다른 기기에서 열면 → 이메일 주소를 한 번 더 확인 후 로그인.
- 같은 이메일로 구글·이메일 링크 두 방식 로그인 → 같은 계정으로 연결.
- 시간대를 바꾸면 → 이미 쓴 학습일지 날짜는 바뀌지 않는다.
- 아이 계정의 아이가 만 14세가 됨 → 일반 계정으로 바꾸기 제안(이메일 연결). 기록은 그대로 이어진다.
- 아이 계정 로그인 코드를 잃어버림 → 보호자가 재발급, 이전 코드는 바로 사용 불가.
