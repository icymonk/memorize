# 통합 오답 노트

> 상태: 확정 · v1.0 · ID 접두어 `WRN`

## 1. 목적
단어 학습, 테스트, 수학에서 틀린 것을 **한곳에 모아** 다시 풀고, 완전히 알게 되면 비운다.

## 2. 사용자 스토리
- 여기저기서 틀린 걸 한 화면에서 모아 보고 싶다.
- 틀린 것만 다시 풀어서 오답 노트를 비우고 싶다.
- 계속 틀리는 것은 따로 표시해서 집중하고 싶다.
- 틀린 문제에 내 메모(왜 틀렸는지)를 남기고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 오답 항목 | 틀린 카드 하나 또는 틀린 문제 하나 |
| 해결 | 다시 풀어서 정해진 횟수만큼 연속으로 맞힌 상태 |

## 4. 기능 명세

### 모으기
| ID | 기능 | 설명 |
| --- | --- | --- |
| WRN-01 | 자동 추가 | 단어 학습에서 틀린 카드, 테스트에서 틀린 문제, 수학에서 틀린 문제를 자동으로 추가 |
| WRN-02 | 직접 추가 | 맞혔지만 헷갈렸던 것을 직접 추가 |
| WRN-03 | 틀린 횟수 | 항목마다 틀린 횟수, 마지막으로 틀린 날, 어디서 틀렸는지(단어장·시험 이름) |

### 보기
| ID | 기능 | 설명 |
| --- | --- | --- |
| WRN-10 | 오답 목록 | 종류(단어/테스트/수학), 과목, 태그, 출처로 필터. 많이 틀린 순·최근 순 정렬 |
| WRN-11 | 자주 틀림 표시 | 3번 이상 틀린 항목은 따로 표시 |
| WRN-12 | 내 메모 | 항목마다 "왜 틀렸는지" 메모 |
| WRN-13 | 오답 노트 공유 | 기본 **나만**. 지정한 사람 / 그룹 / 워크스페이스 멤버에게 공개 선택. 전체 또는 과목별로 따로 설정 (예: 수학 오답만 엄마에게 공유) |

### 다시 풀기
| ID | 기능 | 설명 |
| --- | --- | --- |
| WRN-20 | 다시 풀기 | 고른 항목들로 다시 풀기. 단어는 쓰기 모드, 문제는 원래 문제 형태로 |
| WRN-21 | 해결 처리 | 연속 2번 맞히면 "해결"로 이동 (횟수는 설정 가능). 직접 해결 처리도 가능 |
| WRN-22 | 해결한 항목 | 해결 목록에 보관, 다시 틀리면 오답으로 돌아옴 |
| WRN-23 | 오답으로 단어장·시험 만들기 | 오답 단어로 새 단어장, 오답 문제로 연습 시험 만들기 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| 오답 노트 | 탭: 오답 / 해결. 필터, 다시 풀기 버튼 |
| 항목 상세 | 문제(카드), 내가 쓴 답, 정답·해설(볼 수 있는 경우), 틀린 기록, 메모 |
| 다시 풀기 | 전체 화면 풀기, 끝나면 해결된 개수 |

## 6. 권한
- 오답 노트는 기본적으로 **본인만** 본다 (진도 공유 설정과 별개). 본인이 WRN-13으로 공유한 사람만 볼 수 있다. 공유받은 사람은 보기만 가능.
- 단, 시험 진행자·출제자는 문제별 정답률(누가 틀렸는지는 시험 분석 화면)을 테스트 기능에서 본다.

## 7. 예외 상황
- 원래 카드·문제가 삭제됨 → 오답 항목은 남기고 "원본 삭제됨" 표시, 다시 풀기는 보관된 내용으로.
- 결과가 비공개인 시험의 틀린 문제 → 결과가 공개될 때 오답 노트에 추가.
- 같은 문제를 여러 시험에서 틀림 → 하나의 항목으로 합치고 틀린 횟수만 늘림.
