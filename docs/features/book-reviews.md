# 독후감

> 상태: 확정 · v1.1 · ID 접두어 `REV`

## 1. 목적
책을 읽고 생각을 정리해 기록하고, 원하는 멤버에게 피드백을 받는다. 누구나 쓰는 사람이자 피드백을 주는 사람이 될 수 있다.
독후감은 **노트 기능([notes.md](./notes.md)) 위의 "독후감 모음"** 이다. 편집, 공개 범위, 댓글, 모아 보기를 노트와 똑같이 쓴다.
**내 공간에서도** 쓸 수 있다 (공개 범위는 항상 나만, 피드백·댓글은 없음). 워크스페이스로 복사하면 공유할 수 있다.

## 2. 사용자 스토리
- 정해진 양식(줄거리/느낀 점/인상 깊은 장면)에 맞춰 쉽게 쓰고 싶다.
- 내가 저장한 구절을 독후감에 바로 가져오고 싶다.
- 내 독후감에 특정 멤버(가족, 친구, 선생님)의 피드백을 요청하고 싶다.
- 내가 연 독서 미션에 제출된 독후감, 또는 피드백을 요청받은 독후감에 점수·스탬프·코멘트를 남기고 싶다.
- 모두가 지금까지 쓴 독후감을 표지 갤러리로 모아보고 싶다.

## 3. 기능 명세

### 작성
| ID | 기능 | 설명 |
| --- | --- | --- |
| REV-01 | 쓰기 시작 | 책 화면 "독후감 쓰기" / 독후감 목록 "새 독후감"(책 고르기) / 미션에서 "독후감으로 제출" |
| REV-02 | 독후감 항목 | 책(필수), 별점, 읽은 기간(내 책장에서 자동), 태그, 상태(임시저장/발행), 공개 범위(**기본: 워크스페이스 전체**, "나만 보기" 등 선택 가능), 피드백 요청할 사람 |
| REV-03 | 표지 자동 | 책 표지가 커버로 자동 설정 |
| REV-04 | 템플릿 | 처음 제공하는 기본 템플릿 4종(아래 표). 워크스페이스·개인이 언제든 추가·수정·삭제 가능 |
| REV-05 | 구절 가져오기 | `/구절` → 이 책에서 저장한 내 구절 목록 → 인용으로 넣기 |
| REV-06 | 글자 수 | 글자 수 표시, 미션의 최소 글자 수 조건 표시 |
| REV-07 | 임시저장 | 발행 전까지 나만 볼 수 있음 |
| REV-08 | 그림 독후감 | 그리기 블록([notes.md](./notes.md) NOTE-11)으로 그림·손글씨 독후감 |

기본 템플릿 4종:

| 템플릿 | 구성 | 어울리는 대상 |
| --- | --- | --- |
| 자유형 | 빈 페이지 | 누구나 |
| 기본형 | 줄거리 / 느낀 점 / 인상 깊은 장면 / 나에게 적용할 점 | 청소년·성인 |
| 초등 독서록 | 그림 그리기 / 한 줄 느낌 / 주인공에게 편지 | 초등 |
| 독서 토론형 | 토론하고 싶은 질문 3개 / 나의 답 | 독서 모임 |

### 발행 / 피드백
| ID | 기능 | 설명 |
| --- | --- | --- |
| REV-10 | 발행 | 임시저장 → 발행. 공개 범위에 따라 보이고 활동 피드에 올라감. 미션과 연결돼 있으면 제출 처리 |
| REV-11 | 피드백 요청 | 원하는 멤버에게 요청 → [common.md](./common.md) CMN-23 |
| REV-12 | 피드백 받기 | 요청받은 사람, 제출된 미션의 진행자·리뷰어가 **스탬프 + 총평** (점수는 워크스페이스에서 켤 때만). 여러 명이 각각 남길 수 있다 |
| REV-13 | 문장별 코멘트 | 특정 문장에 코멘트 |
| REV-14 | 다시 쓰기 요청 | 피드백 주는 사람이 "고쳐서 다시 내 주세요" → 글쓴이에게 알림, 상태는 임시저장으로 |
| REV-15 | 댓글·반응 | 공개된 독후감에 멤버 댓글·반응 |

## 4. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| 독후감 모음 | 탭: 전체 / 내 독후감 / 내가 피드백할 것. 갤러리·리스트·표 전환 |
| 새 독후감 | 책 고르기 → 템플릿 고르기 |
| 독후감 쓰기/보기 | 노트 화면 + 위쪽에 책 정보, 아래쪽에 피드백 영역 |

## 5. 권한
| 동작 | 누가 |
| --- | --- |
| 쓰기 | 모든 멤버 |
| 읽기 | 공개 범위 + 피드백 요청받은 사람 + 제출된 미션의 진행자·리뷰어 |
| 피드백 | 요청받은 사람, 제출된 미션의 진행자·리뷰어 |
| 템플릿 관리 | "공유 콘텐츠 작성 가능자" 설정 |

## 6. 예외 상황
- 발행 후 수정 → 수정 시각 표시. 이미 받은 피드백은 유지하되 "피드백 이후 수정됨" 표시.
- 미션 마감 후 발행 → 미션이 늦은 제출을 허용하면 "늦은 제출"로, 아니면 미션과 연결되지 않고 일반 독후감으로.
- 피드백 요청을 받은 사람이 나감 → 요청 취소, 이미 남긴 피드백은 유지.
- 한 책에 독후감 여러 개 → 허용 (다시 읽고 쓴 경우 등).
