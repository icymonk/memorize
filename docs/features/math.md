# 수학 공부

> 상태: 확정 · v1.1 · ID 접두어 `MATH`

## 1. 목적
수식이 들어간 문제를 만들고 풀며, 단원별 성취도와 오답을 관리한다. 문제는 테스트 기능의 문제 은행을 함께 쓴다 ([tests.md](./tests.md)).
대상 학년은 **제한하지 않는다** (초등 연산부터 중고등·성인 문제 풀이까지).

## 2. 사용자 스토리
- 수식이 들어간 문제와 단계별 힌트, 해설을 만들어 멤버들과 공유하고 싶다.
- 다른 멤버가 만든 문제집을 풀고, 내가 만든 문제집에 대한 다른 사람들의 정답률을 보고 싶다.
- 휴대폰에서도 쉽게 수식 답을 입력하고 싶다.
- 구구단·사칙연산을 시간 제한으로 연습하고 기록을 깨고 싶다.
- 틀린 문제를 다시 풀어 오답 노트를 비우고 싶다.
- 문제 형식은 내가 정하고 숫자만 바꿔 가며 여러 번 풀게 하고 싶다.
- 학년·단원만 고르면 그 단원 문제를 바로 만들어 받고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 문제집 | 수학 문제 묶음 (학년·단원별) |
| 힌트 | 단계별로 하나씩 열어보는 도움말 |
| 연산 훈련 | 자동으로 만들어지는 계산 문제를 빠르게 푸는 연습 |
| 변형 문제 | 형식은 그대로 두고 풀 때마다 숫자가 바뀌는 문제 |
| 문제 틀 | 변형 문제의 형식: 지문, 숫자 자리와 범위, 계산 방법, 조건, 정답 구하는 법 |

| --- | --- |

### 문제 만들기 도움
| ID | 기능 | 설명 |
| --- | --- | --- |
| MATH-14 | 변형 문제 만들기 | 지문에 숫자 자리(예: "사과가 {a}개 있고 {b}개를 더 샀어요")를 두고, 자리마다 범위(정수·소수·분수·목록에서 고르기), 계산 방법, 조건(예: 답이 정수로 떨어지게), 정답 구하는 법, 객관식 오답 만드는 법, 힌트·해설을 정한다. "다른 숫자로"를 누르면 예시 5개를 보여 준다. 조건 때문에 숫자를 거의 못 뽑으면 경고하고 저장을 막는다. 자주 쓰는 형식(일차방정식, 분수의 덧셈·뺄셈, 비와 비율, 넓이, 거리·속력·시간, 연립방정식)을 골라 숫자 범위만 바꿔 만들 수도 있다 |
| MATH-15 | 단원별 만들기 | 학년·단원(·세부 개념), 난이도, 개수(5/10/20), 정답 형식(숫자/객관식/섞기)을 고르면 문제 목록을 미리 보여 준다. 빼거나 숫자를 다시 뽑거나 형식을 고친 뒤 새 문제집 또는 기존 문제집에 넣는다. 문제는 앱에 들어 있는 단원별 문제 틀과, 워크스페이스 멤버가 단원을 붙여 공유한 문제 틀에서 고른다. 자유 입력한 단원은 대상이 아니다 |
| MATH-16 | AI 초안 (선택) | 단원·난이도·예시를 주면 AI가 문제 틀 초안을 만든다. 정답은 AI가 아니라 앱이 계산해 확인하고, 확인에 실패한 초안은 버린다. 사람이 보고 저장한다. 사용량에 따라 비용이 들어 하루 한도를 둔다 |

변형 문제는 저장된 것이 형식이라 풀 때마다 숫자가 바뀐다. 다시 풀기·오답 노트에서 다시 풀 때도 다른 숫자가 나온다. 정답 구하는 법은 출제자만 본다.

## 7. 예외 상황
- 수식 답이 맞는데 다른 형태로 써서 오답 처리됨 → "이의 신청" 버튼으로 출제자에게 알림, 출제자가 정답으로 인정 가능.
- 풀이 사진이 채점되지 않은 채 오래됨 → 7일 후 작성자에게 다시 알림.
- 연산 훈련 중 앱을 벗어남 → 기록하지 않고 종료.
- 변형 문제에 이의 신청 → 그때 나온 숫자와 함께 출제자에게 보낸다.
- 변형 문제의 형식을 고침 → 이미 열린 시험은 그대로, 이후 풀기부터 새 형식.
- 단원별 만들기에서 그 단원 문제 틀이 모자람 → 있는 만큼만 만들고 개수를 알려 준다.
