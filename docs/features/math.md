# 수학 공부

> 상태: 확정 · v1.0 · ID 접두어 `MATH`

## 1. 목적
수식이 들어간 문제를 만들고 풀며, 단원별 성취도와 오답을 관리한다. 문제는 테스트 기능의 문제 은행을 함께 쓴다 ([tests.md](./tests.md)).
대상 학년은 **제한하지 않는다** (초등 연산부터 중고등·성인 문제 풀이까지).

## 2. 사용자 스토리
- 수식이 들어간 문제와 단계별 힌트, 해설을 만들어 멤버들과 공유하고 싶다.
- 다른 멤버가 만든 문제집을 풀고, 내가 만든 문제집에 대한 다른 사람들의 정답률을 보고 싶다.
- 휴대폰에서도 쉽게 수식 답을 입력하고 싶다.
- 구구단·사칙연산을 시간 제한으로 연습하고 기록을 깨고 싶다.
- 틀린 문제를 다시 풀어 오답 노트를 비우고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 문제집 | 수학 문제 묶음 (학년·단원별) |
| 힌트 | 단계별로 하나씩 열어보는 도움말 |
| 연산 훈련 | 자동으로 만들어지는 계산 문제를 빠르게 푸는 연습 |

## 4. 기능 명세

### 수식
| ID | 기능 | 설명 |
| --- | --- | --- |
| MATH-01 | 수식 보기 | 지문·해설·노트에서 수식을 보기 좋게 표시 |
| MATH-02 | 수식 입력 | 화면 수식 키보드(분수, 루트, 지수 등), 휴대폰 지원. 익숙한 사람은 수식 기호로 직접 입력 |

### 문제집 / 문제
| ID | 기능 | 설명 |
| --- | --- | --- |
| MATH-10 | 문제집 만들기 | 제목, 학년·단원, 문제 목록, 공개 대상, 편집 범위 |
| MATH-13 | 학년·단원 분류 | **교육과정 기준 목록에서 고르기 + 자유 입력** 둘 다 가능. 자유 입력한 단원도 필터·성취도에 그대로 쓰인다 |
| MATH-11 | 수학 문제 항목 | 문제 은행 공통 항목 + 단원·개념 태그, 난이도(1~5), 단계별 힌트, 해설(이미지·수식) |
| MATH-12 | 정답 형식 | 아래 표 |

| 형식 | 채점 |
| --- | --- |
| 숫자 | 허용 오차, 분수·소수 같은 값 인정 (예: 1/2 = 0.5) |
| 객관식 | 일반 |
| 수식 | 띄어쓰기·순서 차이 정도는 같은 답으로 인정. 더 정교한 판정은 이후 단계 |
| 풀이 사진 | 풀이를 찍어 올리면 문제집 작성자 또는 피드백 요청받은 멤버가 채점 |

### 풀기
| ID | 기능 | 설명 |
| --- | --- | --- |
| MATH-20 | 문제집 풀기 | 한 문제씩, 답 입력 → 바로 채점 |
| MATH-21 | 힌트 | 한 단계씩 열기. 힌트 사용 여부 기록 (점수 감점은 문제집 설정) |
| MATH-22 | 풀이 메모 | 문제마다 내 풀이 메모 (노트처럼 작성) |
| MATH-23 | 해설 보기 | 맞혔거나 포기했을 때 |
| MATH-24 | 내 문제 풀기 | 내가 만든 문제를 풀면 "연습"으로 기록, 통계 제외 |
| MATH-25 | 시험으로 내기 | 문제집 문제로 테스트 열기 → [tests.md](./tests.md) |

## 6. 권한
| 동작 | 누가 |
| --- | --- |
| 문제집·문제 만들기 | "공유 콘텐츠 작성 가능자" 설정 (기본 모든 멤버) |
| 정답·해설 미리 보기 | 출제자 (다른 사람은 풀고 난 뒤) |
| 풀기, 연산 훈련 | 모든 멤버 |
| 풀이 사진 채점 | 문제집 작성자, 피드백 요청받은 멤버 |

## 7. 예외 상황
- 수식 답이 맞는데 다른 형태로 써서 오답 처리됨 → "이의 신청" 버튼으로 출제자에게 알림, 출제자가 정답으로 인정 가능.
- 풀이 사진이 채점되지 않은 채 오래됨 → 7일 후 작성자에게 다시 알림.
- 연산 훈련 중 앱을 벗어남 → 기록하지 않고 종료.
