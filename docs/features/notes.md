# 노트 · 학습일지 (노션형 기록)

> 상태: 확정 · v1.1 · ID 접두어 `NOTE`

## 1. 목적
학습 과정에서 생기는 모든 글(학습일지, 독후감, 정리 노트, 강의 필기)을 **노션처럼 블록 단위로 자유롭게 기록**하고, **표·캘린더·갤러리로 모아 다시 확인**할 수 있게 한다.

독후감([book-reviews.md](./book-reviews.md))과 강의 필기([courses.md](./courses.md))도 이 노트 기능을 그대로 쓴다.

## 2. 사용자 스토리
- 매일 오늘 공부한 내용을 간단히 기록하고, 달력으로 지난 기록을 훑어보고 싶다.
- 오늘 한 학습(복습한 카드 수, 읽은 페이지, 푼 문제)이 일지에 자동으로 채워졌으면 좋겠다.
- 문법 정리 노트를 하위 페이지로 나누고, 단어장이나 책을 노트 안에 넣고 싶다.
- 같은 워크스페이스 멤버들의 학습일지를 한 화면(캘린더/표)에서 보고 코멘트를 남기고 싶다.
- 내 일지나 정리 노트에 특정 멤버의 피드백을 요청하고 싶다 (친구끼리, 가족끼리 서로).
- 공유 페이지(스터디 규칙, 발표 정리)를 함께 편집하고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 페이지 | 제목, 아이콘, 커버, 본문을 가진 문서. 다른 페이지 안에 넣을 수 있다 |
| 블록 | 본문을 이루는 단위. 문단, 제목, 목록, 체크박스, 이미지 등 |
| 모음 | 같은 항목(날짜, 과목, 기분 등)을 가진 페이지들의 묶음. 학습일지·독후감이 모음이다 |
| 항목 | 모음 안 페이지마다 채우는 정보. 날짜, 선택, 태그, 숫자, 체크, 사람, 연결(책·단어장 등) |
| 보기 | 모음을 보여주는 방식(리스트/캘린더/표/갤러리) + 필터·정렬 |
| 템플릿 | 새 페이지를 만들 때 미리 채워지는 내용 |

> 범용 노션을 복제하지 않는다. 모음은 **기본 모음(학습일지, 독후감)** 과 **사용자가 직접 만드는 모음**(예: "영어 표현 모음", "수학 공식 정리")을 지원하되, 수식 계산·자동화 같은 범용 기능은 넣지 않는다.

### 학습일지
| ID | 기능 | 설명 |
| --- | --- | --- |
| NOTE-30 | 날짜별 일지 | **하루에 몇 장이든** 쓸 수 있다 (예: 영어 일지, 수학 일지 따로). 캘린더에는 그날 일지 개수를 표시하고, 날짜를 누르면 그날 일지 목록 + 새로 쓰기 |
| NOTE-31 | 일지 항목 | 날짜(필수), 과목(여러 개), 학습 시간(분), 기분(이모지 5단계), 만족도(별 5개), 태그, 공개 범위 |
| NOTE-32 | 오늘의 학습 자동 요약 | 그날 한 학습을 자동으로 모아 보여주는 블록 (항목은 아래 표). 그날 첫 일지에 자동으로 들어가고, 다른 일지에는 원하면 넣는다. 과목을 고른 일지는 그 과목 활동만 보여줄 수 있다 |
| NOTE-33 | 요약 고정 | 기본은 하루가 끝날 때 그날 요약을 고정. 원하면 "다시 계산" |
| NOTE-34 | 학습 시간 자동 제안 | 그날 기록된 학습 시간을 합쳐 기본값으로 채움 (수정 가능) |
| NOTE-35 | 기본 템플릿 | "오늘 배운 것 / 어려웠던 점 / 내일 할 것(체크리스트)". 워크스페이스·개인이 수정 가능 |
| NOTE-36 | 지난 날 작성 | 캘린더에서 지난 날짜를 눌러 늦게 쓰기 가능 (늦게 쓴 표시) |
| NOTE-37 | 일지 연속 작성일 | 학습 연속일과 따로 표시 |
| NOTE-38 | 작성 리마인더 | 정한 시각까지 안 썼으면 알림 |
| NOTE-39 | 내 일지 모아 보기 | 일지는 워크스페이스마다 따로 쓰고 공개도 워크스페이스별로 정해지지만, **본인은 모든 워크스페이스의 내 일지를 한 캘린더·리스트에서** 볼 수 있다. 워크스페이스별 색으로 구분, 필터 가능. 다른 사람에게는 보이지 않는다 |

오늘의 학습 자동 요약에 들어가는 항목 (활동이 있는 것만 표시, 항목별로 켜고 끌 수 있음):

| 분류 | 항목 | 예시 |
| --- | --- | --- |
| 전체 | 총 학습 시간, 연속 학습일, 오늘 받은 포인트·뱃지 | 1시간 25분 · 12일째 · +35점 |
| 단어 | 복습·학습한 카드 수, 정답률, 새로 외운 카드 수, 단어장 이름, 매칭 기록 | 42장 복습 (토익 Day3, 86%) · 새로 외움 8 |
| 강의 | 완료한 레슨, 들은 시간 | 「3주차 현재완료」 완료 |
| 독서 | 읽은 책·쪽 범위·시간, 저장한 구절 수, 완독한 책 | 『어린 왕자』 32~58쪽 (25분) |
| 독후감·노트 | 발행한 독후감, 새로 쓴 노트 | 독후감 1편 발행 |
| 미션 | 완료한 미션, 제출한 미션, 남은 오늘 미션 | 2개 완료 · 1개 남음 |
| 테스트 | 응시한 시험과 점수 | 주간 모의고사 82점 |
| 수학 | 푼 문제 수·정답 수, 연산 훈련 기록 | 15문제 (12개 정답) · 구구단 60초 34개 |
| 오답 노트 | 새로 쌓인 오답, 해결한 오답 | 오답 +5 · 해결 3 |
| 함께한 것 | 받은 피드백·댓글, 내가 남긴 피드백 | 피드백 2개 받음 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| 노트 홈 | 최근, 즐겨찾기, 내 페이지/공유 페이지 계층 |
| 페이지 | 왼쪽 페이지 계층, 가운데 본문, 오른쪽 접이식 패널(항목·댓글·목차) |
| 내 학습일지 | 기본 캘린더 보기, 보기 전환(리스트/표) |
| 날짜별 일지 | 해당 날짜 페이지. 없으면 템플릿으로 새로 만들기 |
| 멤버 일지 | 나에게 공개된 멤버 일지, 멤버 × 날짜 표 |
| 휴지통 | 삭제한 페이지, 복원/완전 삭제 |

- 모바일: 페이지 계층은 아래에서 올라오는 창으로, 블록 메뉴는 키보드 위 도구 막대로.

## 6. 권한
| 동작 | 누가 |
| --- | --- |
| 내 페이지 만들기 | 모든 멤버 (설정과 무관) |
| 공유 페이지 만들기 | "공유 콘텐츠 작성 가능자" 설정 (기본 모든 멤버) |
| 읽기 | 공개 범위 + 자동 공유(NOTE-53). **운영 권한이 있어도 남의 비공개 노트는 볼 수 없다** |
| 편집 | 글쓴이, 공동 편집자, (공유 페이지) 모든 멤버 |
| 공개 범위·공동 편집자·피드백 요청 바꾸기 | 글쓴이만 |
| 삭제 | 글쓴이. 공유 페이지는 매니저도 가능 |

## 7. 예외 상황
- 두 사람이 거의 동시에 편집 → 나중 사람은 "다른 사람이 수정했습니다" 안내 후 최신본 불러오기 / 내 내용으로 덮어쓰기 선택.
- 연결 블록이 가리키는 단어장·책을 볼 권한이 없음 → "볼 수 없는 항목"으로 표시.
- 연결된 단어장·책이 삭제됨 → "삭제된 항목"으로 표시, 노트 본문은 유지.
- 상위 페이지를 휴지통에 버림 → 하위 페이지도 함께 휴지통으로, 복원도 함께.
- 오프라인에서 작성 → 연결되면 자동 저장.
- 페이지가 너무 길어짐(이미지 다수) → 일정 크기 이상이면 페이지를 나누라는 안내.
- 하루에 일지가 여러 장 → 연속 작성일은 하루 1장 이상이면 인정, 일지 작성 포인트는 하루 1회분만.
- 사용자 모음의 항목을 지우거나 종류를 바꿈 → 이미 입력된 값이 사라질 수 있다고 경고 후 진행.
