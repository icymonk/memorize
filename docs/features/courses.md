# 강의자료

> 상태: 확정 · v1.1 · ID 접두어 `CRS`

## 1. 목적
누구나 강의 자료(설명, 문서, 듣기 파일, 영상 등)를 코스로 엮어 올릴 수 있고, 다른 멤버의 코스를 순서대로 학습하며 단어장·테스트·미션으로 이어지게 한다.
**외국어뿐 아니라 수학, 독서, 그 밖의 모든 과목에서 쓰는 공용 기능**이다.

## 2. 사용자 스토리
- 주차별 레슨에 설명, 듣기 파일, 숙제 단어장을 묶어 올리고 싶다 (선생님일 수도, 먼저 공부한 스터디원일 수도 있다).
- 가지고 있는 자료(PDF, 한글·워드·파워포인트 파일, 영상, 녹음)를 형식 걱정 없이 올리고 싶다.
- 다른 멤버와 코스를 함께 만들고 싶다 (레슨을 나눠 맡기).
- 레슨을 순서대로 듣고, 완료 체크하고, 필기를 남기고 싶다.
- 레슨마다 숙제(미션)를 붙이고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 코스 | 레슨 묶음 (예: "초급 영어 회화", "중2 함수") |
| 레슨 | 한 번에 공부할 단위. 자료 여러 개 + 연결된 단어장·테스트·미션 |
| 자료 | 레슨 안의 본문, 문서, 오디오, 영상, 이미지, 링크, 파일 |

```
코스
 └─ 레슨
     ├─ 자료 (본문 / 문서 / 오디오 / 영상 / 이미지 / 링크 / 기타 파일)
     ├─ 연결된 단어장 · 문제집
     ├─ 확인 테스트
     └─ 레슨 미션 (숙제)
```

## 4. 기능 명세

### 코스 / 레슨 만들기
| ID | 기능 | 설명 |
| --- | --- | --- |
| CRS-01 | 코스 만들기 | 제목, 설명, 커버, 과목(워크스페이스 공통 과목 목록), 수준, 공개 대상(전체/그룹), 편집 범위(작성자만 / 지정한 사람 / 모든 멤버) |
| CRS-02 | 레슨 만들기 | 제목, 자료 추가, 단어장·문제집·테스트 연결 |
| CRS-03 | 순서 바꾸기 | 레슨·자료를 끌어서 순서 변경 |
| CRS-04 | 예약 공개 | 정한 날짜에 레슨이 열림 |
| CRS-05 | 순서대로 열기 | 앞 레슨을 완료해야 다음 레슨이 열림 (선택) |
| CRS-06 | 레슨 미션 | 레슨에 숙제를 바로 붙이기. 레슨을 보는 사람에게 미션이 함께 보이고, 미션 기능으로 제출·검토 ([missions.md](./missions.md)) |
| CRS-07 | 코스 복사 | 코스(레슨·자료 포함)를 내가 속한 다른 워크스페이스로 복사. 연결된 단어장·테스트·미션은 복사할지 선택 → [workspace.md](./workspace.md) WS-60~64 |

### 자료
**다양한 형식을 올릴 수 있는 것**을 우선한다.

| ID | 유형 | 설명 |
| --- | --- | --- |
| CRS-10 | 본문 | 노트와 같은 편집기로 작성 ([notes.md](./notes.md)) |
| CRS-11 | PDF | 화면 안에서 바로 보기, 페이지 이동 |
| CRS-12 | 오디오 | 업로드 또는 녹음. 속도 조절(0.5~2배), A-B 구간 반복, 10초 앞/뒤 |
| CRS-13 | 영상 | **직접 업로드** 또는 유튜브 등 링크. 속도 조절, 구간 반복 |
| CRS-14 | 이미지·링크 | 이미지 갤러리, 외부 링크 미리보기 |
| CRS-15 | 문서 파일 | 한글, 워드, 파워포인트, 엑셀. 화면 안 미리보기(가능한 형식) + 내려받기 |
| CRS-16 | 기타 파일 | 그 밖의 파일은 내려받기로 제공 |
| CRS-17 | 스크립트 따라가기 | 오디오·영상 재생 위치에 맞춰 스크립트 강조 (이후 단계) |

### 학습
| ID | 기능 | 설명 |
| --- | --- | --- |
| CRS-20 | 레슨 학습 | 자료를 순서대로 보고, 아래에 "단어 공부하기", "확인 테스트 보기", "숙제 하기" 버튼 |
| CRS-21 | 완료 체크 | 직접 체크, 또는 "확인 테스트 통과 / 숙제 완료 시 자동 완료" (코스 설정) |
| CRS-22 | 진도 | 코스 진도율 = 완료한 레슨 / 전체. 멤버별 진도 (숨긴 멤버 제외) |
| CRS-23 | 필기 | 레슨마다 내 필기 노트 (기본 "나만"). 레슨 화면 옆에 열림 |
| CRS-24 | 형광펜 | 본문·PDF에 내 형광펜 표시 |
| CRS-25 | 단어장에 추가 | 본문 단어를 선택해 내 단어장에 추가 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| 코스 목록 | 과목별 필터, 코스 카드, 내 진도율 |
| 코스 상세 | 레슨 목록(완료/잠김 표시), 진도, 멤버 진도 |
| 레슨 학습 | 왼쪽 자료, 오른쪽 필기 패널(접기 가능), 아래 단어장·테스트·숙제 버튼 |
| 코스 편집 | 레슨·자료 추가(파일 끌어놓기), 순서 변경, 공개 설정 |

## 6. 권한
| 동작 | 누가 |
| --- | --- |
| 코스 만들기 | "공유 콘텐츠 작성 가능자" 설정 (기본 모든 멤버) |
| 코스 편집 | CRS-01 편집 범위에 따름 |
| 레슨 미션 붙이기 | 코스 편집 가능자 + "미션·테스트 진행 가능자" 설정 |
| 학습·필기 | 모든 멤버 (작성자 포함) |

## 7. 예외 상황
- 연결된 단어장·테스트가 삭제됨 → 레슨에서 "삭제된 항목" 표시, 작성자에게 알림.
- 연결된 테스트를 볼 권한이 없음(대상이 아님) → 버튼 숨김.
- 순서대로 열기인데 앞 레슨이 삭제됨 → 다음 레슨 자동으로 열림.
- 레슨을 완료한 뒤 내용이 크게 바뀜 → 완료 상태 유지, "업데이트됨" 표시.
- 화면 안 미리보기가 안 되는 파일 → 파일 이름·크기와 내려받기 버튼만 표시.
- 영상·파일이 용량 제한(계정당 2GB)을 넘음 → 업로드 전에 안내, 유튜브 링크 등 대안 제시.
