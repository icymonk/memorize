## 2. 결정됨

## 3. 개발 단계에서 결정 (보류)
개발 문서 작성 시 다룬다.
- 서버 기능 도입 시점과 요금제
- 무료 한도의 구체 값 (워크스페이스 최대 인원 등) — 비용을 보고 넉넉하게
- 노트 저장 방식
- 책 검색에 쓸 외부 서비스
- 간격 반복 알고리즘 상세
- 문서 파일(한글·워드·파워포인트) 미리보기 방식
- 오류 추적 도구 (Firebase 안에서 해결 / 외부 서비스)
