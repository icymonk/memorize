# 사용자와 역할 모델

> 상태: 확정 · v1.1

## 1. 핵심 원칙: 사람에게 고정된 역할은 없다

> **누구나 배우고, 만들고, 이끌 수 있다.**
> 역할은 사람이 아니라 **행동과 콘텐츠**에 붙는다.

- "선생님 계정 / 학생 계정" 같은 구분이 없다. 모든 멤버는 같은 기능을 쓸 수 있다.
- 같은 사람이 같은 워크스페이스 안에서 오늘은 단어를 외우고(배우기), 단어장을 만들고(만들기), 다른 멤버에게 미션을 열어 검토한다(이끌기).
- 내가 연 미션에 나도 참여할 수 있고, 다른 사람이 연 미션의 참여자가 될 수도 있다.
- 화면도 "학습자 화면 / 관리자 화면"으로 나누지 않는다. 각 화면에서 **내가 참여 중인 것**과 **내가 연 것**을 탭으로 함께 보여준다.

## 2. 세 가지 활동 모드

| 모드 | 하는 일 | 예 |
| --- | --- | --- |
| **배우기** | 학습, 기록, 응시, 제출 | 단어 복습, 학습일지 작성, 독서 기록, 테스트 응시, 미션 수행 |
| **만들기** | 콘텐츠 작성·공동 편집 | 단어장, 강의자료, 문제, 공유 노트, 템플릿 |
| **이끌기** | 다른 사람의 활동을 열고 확인 | 미션·테스트·함께 읽기 열기, 대상 지정, 현황 보기, 검토·채점·피드백 |

## 3. 상황별 역할 (콘텐츠 하나에 대해서만 의미가 있음)

| 역할 | 누가 되나 | 할 수 있는 것 |
| --- | --- | --- |
| **작성자** | 콘텐츠를 만든 사람 | 편집·삭제, 공동 편집자/진행자/리뷰어 지정 |
| **공동 편집자** | 작성자가 추가한 사람 (또는 "모두 편집 가능"으로 설정된 경우 모든 멤버) | 편집 |
| **진행자** | 미션·테스트·함께 읽기를 연 사람 + 공동 진행자로 추가된 사람 | 대상 지정, 현황 보기, 채점, 승인/반려 |
| **리뷰어** | 진행자가 지정한 공동 검토자, 또는 글쓴이가 피드백을 요청한 사람 | 제출물·글에 피드백(점수·스탬프·코멘트) |
| **참여자** | 대상으로 지정되었거나 스스로 참여한 사람 | 학습·응시·제출 |

- 한 사람이 같은 콘텐츠에서 **진행자이자 참여자**일 수 있다 (예: 스터디장이 미션을 열고 본인도 수행).
  - 단, 테스트 진행자나 문제를 만든 사람은 정답을 알기 때문에, 본인 응시는 **"연습 응시"** 로 표시되고 평균·순위에서 빠진다.
  - 미션 진행자는 본인 제출을 스스로 승인할 수 없다.
- 콘텐츠별 편집 범위: **작성자만** / **작성자 + 지정한 사람** / **모든 멤버** 중 선택.

## 4. 워크스페이스 운영 권한

학습 기능과 별개로, **워크스페이스 자체를 관리하는 권한**만 따로 둔다.

| 운영 권한 | 할 수 있는 것 |
| --- | --- |
| **소유자** | 아래 전부 + 워크스페이스 삭제, 소유권 넘기기. 워크스페이스당 1명 |
| **매니저** | 가입 승인·멤버 내보내기, 매니저 지정, 워크스페이스 설정 변경, 부적절한 공유 콘텐츠 정리 |
| **멤버** | 학습 기능 전부 (배우기·만들기·이끌기) |

- 매니저와 멤버의 **학습 기능은 완전히 같다.**
- 운영 권한이 있어도 **남의 비공개 노트·숨긴 진도는 볼 수 없다.**
- 소규모·수평적 그룹은 소유자 외 모두 멤버로 두면 된다.
- 운영 방식 설정 (기본값은 모두 "모든 멤버"):

| 설정 | 선택지 | 쓰임 |
| --- | --- | --- |
| 초대할 수 있는 사람 | 모든 멤버 / 매니저만 | |
| 공유 콘텐츠를 만들 수 있는 사람 | 모든 멤버 / 매니저만 | 학원처럼 자료를 일부만 올리게 할 때 |
| 다른 사람 대상 미션·테스트를 열 수 있는 사람 | 모든 멤버 / 매니저만 | 학원처럼 과제를 일부만 내게 할 때 |
| 진도·통계 공유 | 멤버끼리 공유 / 본인만 | |

> 이 설정도 **사람에게 역할을 정하는 것이 아니라 그룹 운영 방식의 선택**이다. 자기 자신만 대상인 개인 목표 미션, 개인 노트는 설정과 무관하게 항상 만들 수 있다.

## 5. 공유와 프라이버시
- 워크스페이스는 공유가 기본이다. 학습 진도·활동은 멤버끼리 보인다.
- 각자 **내 진도 숨기기**를 켤 수 있다 (워크스페이스마다 따로).
- 노트(학습일지·독후감 포함)의 공개 범위는 글쓴이가 정한다 → [features/notes.md](../features/notes.md).
- 미션에 제출한 것은 그 미션의 진행자·리뷰어에게 자동으로 공유된다.
- **내 공간**(워크스페이스 밖)의 개인 단어장·노트는 나만 본다. 워크스페이스로 복사해야 다른 사람이 볼 수 있다 → [features/workspace.md](../features/workspace.md) WS-50~54.
- **예외: 보호자.** 만 14세 미만 아이 계정은 보호자가 만들고 관리하며, 보호자는 아이의 모든 기록(비공개 노트 포함)을 볼 수 있다. 이것은 워크스페이스 역할이 아니라 **계정 사이의 관계**다. 아이 화면에는 보호자가 볼 수 있다는 표시가 항상 나온다 → [features/account.md](../features/account.md) ACC-06~09.

## 6. 사용 시나리오 (같은 사람이 여러 모드를 오감)
1. **토익 스터디 (수평형)**: 민수는 Day 1~10 단어장을 만들고(만들기), 지수가 만든 Day 11~20으로 복습한다(배우기). 이번 주 모의 테스트는 민수가 열고 채점한다(이끌기). 다음 주에는 지수가 진행하고 민수가 응시한다.
2. **가족**: 엄마는 아이의 독후감에 피드백을 남기고(이끌기), 본인은 일본어 단어를 외우며 학습일지를 쓴다(배우기). 아이는 엄마에게 "매일 단어 10개" 미션을 열어준다(이끌기).
3. **학원 반**: 선생님이 단어장·테스트를 만들고 진행한다. 학생도 자기 정리 노트를 공유하고, 친구들끼리 매칭 게임 미션을 연다. 학원은 "미션·테스트를 열 수 있는 사람: 매니저만"으로 운영할 수도 있다.
