# 출시 단계 & 성공 지표

> 상태: 확정 · v1.1

## 1. 출시 단계

> 단계는 **기능 묶음**이다. 묶음 사이의 출시 순서는 고정하지 않고 개발 상황에 따라 바꿀 수 있다. 단, 0단계(기반)는 가장 먼저 필요하다.

| 단계 | 사용자가 할 수 있게 되는 것 | 완료 기준 |
| --- | --- | --- |
| **0 – 기반** | 가입·로그인, 워크스페이스 만들기·전환, 초대 링크/코드로 참여, 멤버 목록 | 2명 이상이 같은 워크스페이스에 들어와 서로를 볼 수 있음 |
| **1 – 단어 학습 + 노트 기본** | **내 공간**(개인 단어장·노트), 내 공간·워크스페이스 간 복사(단어장·노트), 단어장 만들기·붙여넣기(카드 항목 전체), 낱말카드/학습하기/쓰기/매칭, 간격 반복 복습(오늘의 복습), 내 진도, 활동 피드 / 노트 작성·페이지 계층·개인/공유, **내 모음 만들기 + 리스트·캘린더·표 보기** / **간단한 개인 목표(체크형)** | 단어장을 공유하고 각자 학습 기록이 남음. 노트·모음을 만들고 볼 수 있음 |
| **2 – 기록 · 독서 · 미션** | 학습일지(하루 여러 장, 템플릿, 오늘의 학습 자동 요약, 내 일지 모아 보기, 멤버 일지 보기), 책장·독서 기록(전자책·오디오북 포함), 독후감·스탬프 피드백, 미션(체크형·제출형·개인 목표 전체), 댓글·반응·알림, 보호자가 만드는 아이 계정(보호자 여러 명), 공통 과목 목록 | 학습일지를 캘린더로 보고, 미션을 연 사람이 제출물을 검토할 수 있음 |
| **3 – 테스트 · 강의자료** | 문제 은행(내 문제·공유·복사), 시험 출제·응시·채점·분석, 시험을 미션으로 배정, 강의자료(모든 과목, 다양한 파일), 레슨 미션, 함께 읽기·챕터 일정, 책 추천, 통합 오답 노트, 푸시 알림, 노트 갤러리·버전 기록·그리기 블록, **수학 문제집·변형 문제·단원별 만들기(4단계에서 앞당김)** | 레슨 → 단어 → 테스트 흐름을 끝까지 진행 가능 |
| **4 – 수학 · 포인트** | 수학 시험(응시자마다 다른 숫자), 성취도, 연산 훈련, 포인트·뱃지·랭킹(악용 방지 포함), 자동 확인형 미션, 서로 검토 미션 | 수학 문제를 풀고 성취도를 확인 가능 |
| **5 – 확장** | 노트 실시간 공동 편집, AI 기능(카드 자동 생성, 사진 글자 인식, 요약), 오프라인, 다국어 | — |

## 2. 성공 지표

| 지표 | 정의 |
| --- | --- |
| 워크스페이스 활성도 | 주간 활동 멤버 / 전체 멤버 |
| 학습 빈도 | 멤버당 주간 학습 횟수, 평균 연속 학습일 |
| 기록 습관 | 멤버당 주간 학습일지 작성 수, 일지 연속 작성일 |
| 과제 수행 | 미션 완료율, 독후감 제출률 |
| 참여 다양성 | 콘텐츠를 만들거나 미션·테스트를 연 적이 있는 멤버 비율 (역할이 고르게 도는지) |
| 첫 경험 | 초대 링크 → 가입 비율, 단어장 생성 → 첫 학습 비율 |

- 성공 지표 사이의 우선순위는 따로 두지 않는다.
