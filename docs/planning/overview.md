# 서비스 개요

> 상태: 확정 · v1.1 · 2026-10-06

## 1. 한 줄 정의
**여러 명이 "워크스페이스"로 모여 외국어·독서·수학 등 다양한 학습 활동을 함께 만들고, 기록하고, 서로의 진행 상황을 확인하는 그룹 학습 서비스.**

## 2. 배경 / 문제
- 단어 암기(Quizlet), 독서 기록, 문제집, 노트(Notion)가 각각 다른 앱에 흩어져 있어 **그룹(가족, 스터디, 학원 반, 동아리)** 단위로 함께 쓰기 어렵다.
- 기존 앱은 "선생님 / 학생"처럼 역할을 고정한다. 하지만 실제로는 **같은 사람이 어떤 날은 배우고, 어떤 날은 자료를 만들고, 어떤 날은 미션을 열어 다른 사람을 이끈다.**
- 모두가 자기 학습을 하고 **학습일지·독후감을 남기며**, 서로의 진행 상황을 보고 동기부여를 받고 싶다.

## 2-1. 대상
- **연령·용도 제한 없이 전체**: 초등생 가족, 학원 반, 청소년·성인 스터디, 혼자 공부하는 사람까지.
- 만 14세 미만은 보호자가 만드는 아이 계정으로 사용한다 → [features/account.md](../features/account.md).
- 혼자 공부할 때는 워크스페이스 없이 **내 공간**(개인 단어장·노트)만으로도 쓸 수 있다.
- 화면은 특정 연령에 치우치지 않게 하고, 템플릿(초등 독서록 등)과 설정으로 그룹 성격에 맞춘다.

## 3. 목표
1. 워크스페이스 단위로 **콘텐츠와 활동이 자연스럽게 공유**된다.
2. 여러 학습 기능이 **공통 기반(멤버·피드·알림·포인트·노트)** 위에 얹혀, 기능이 늘어나도 사용법이 일관된다.
3. 학습 기록(진도, 오답, 암기 상태)은 각자의 것이지만 멤버끼리 공유된다 (본인이 숨길 수 있음).
4. 모든 학습 활동을 **노션처럼 자유롭게 기록하고 다시 찾아볼 수 있다** (학습일지, 독후감, 정리 노트).
5. **고정된 역할이 없다.** 누구나 배우고, 만들고, 이끌 수 있다 → [users-and-roles.md](./users-and-roles.md).

## 4. 비목표 (초기 범위 밖)
- 실시간 화상 수업, 워크스페이스 밖 공개 마켓플레이스·공개 링크 공유(워크스페이스 간에는 복사만), 스마트폰 앱(초기엔 모바일 웹으로 대응).
- 결제/구독: 초기엔 없음. **무료에서 최대한 지원**하고, 추후 유료 플랜(인원·용량 확대 등)을 붙일 수 있게 한다.
- 노션 수준의 범용 협업 툴(수식 데이터베이스, 자동화 등). **학습 기록에 필요한 만큼만** 만든다.

## 5. 기능 지도

```
사용자 ─┬─ 내 공간 (나만: 개인 단어장 · 개인 노트/모음)
        │        ▲ 복사 ▼
        └─(여러 워크스페이스에 소속)── 워크스페이스 ◀─ 복사 ─▶ 다른 워크스페이스
                                        │
        ┌───────────────────────────────┼───────────────────────────────┐
        │ 공통 기반                      │ 학습 기능                      │
        │ - 멤버 / 그룹 / 초대            │ - 외국어 학습 (단어장)          │
        │ - 홈 / 활동 피드               │ - 강의자료                     │
        │ - 댓글 / 피드백 / 알림          │ - 독서                         │
        │ - 포인트 / 뱃지 / 랭킹          │ - 독후감 ─────────┐            │
        │ - 검색 / 태그                  │ - 미션            │            │
        │ - 노트 / 학습일지 ◀────────────┼───────────────────┘            │
        │ - 통합 오답 노트 ◀─────────────┼── 외국어 · 테스트 · 수학        │
        │                               │ - 테스트                       │
        │                               │ - 수학                         │
        └───────────────────────────────┴────────────────────────────────┘
```

## 6. 핵심 개념
| 개념 | 설명 |
| --- | --- |
| 워크스페이스 | 함께 공부하는 모임 단위. 공유의 경계 |
| 내 공간 | 워크스페이스 밖의 나만의 공간. 개인 단어장·노트를 둔다 |
| 복사 | 내 공간과 워크스페이스, 워크스페이스끼리 콘텐츠를 나누는 유일한 방법 |
| 공유 콘텐츠 | 워크스페이스에 올라가 멤버가 함께 쓰는 것 (단어장, 강의자료, 책 목록, 미션, 테스트, 공유 노트) |
| 개인 학습 기록 | 각자의 암기 상태, 진도, 응시 결과. 기본적으로 멤버에게 보이고, 본인이 숨길 수 있음 |
| 상황별 역할 | 작성자·공동 편집자·진행자·리뷰어·참여자. 사람이 아니라 **콘텐츠 하나에 대해** 정해짐 |
| 기록(노트) | 직접 쓰는 글. 학습일지·독후감·정리 노트·강의 필기가 모두 같은 노트 방식으로 동작 |
| 활동 | 각 기능에서 일어난 주요 일(복습 완료, 완독, 미션 완료 등). 피드와 학습일지 자동 요약에 쓰임 |
